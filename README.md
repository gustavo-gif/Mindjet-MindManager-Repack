## ⚙️ Usage Guide

After installing Mindjet-MindManager-Repack, you can start using it right away:

1. **Create a New Mind Map**:
   - Open the app and select "New Map."

2. **Adding Nodes**:
   - Click on the main idea and select "Add Node."
